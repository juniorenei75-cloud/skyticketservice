⚠ Se viu «Connection unexpectedly closed»

A sua rede/operadora está a bloquear o SMTP do Gmail (portas 587/465). A senha de aplicação está correcta, mas o servidor fecha a ligação.

Solução recomendada: use o modo SendGrid ou Brevo (API HTTPS) abaixo — usam a porta 443 como um site normal.

Como activar SendGrid (recomendado)

  1. Crie conta em sendgrid.com.
  2. Vá a Settings → API Keys → Create API Key (permissão Mail Send).
  3. Em Sender Authentication, verifique o remetente skyticketservicee@gmail.com (ou o e-mail From).
  4. Abaixo: modo = SendGrid, cole a API key, guarde e teste.

Como activar Brevo (alternativa)

  1. Crie conta grátis em app.brevo.com (pode usar o e-mail da agência).
  2. Confirme o e-mail da conta Brevo.
  3. Vá a SMTP & API → API keys → criar chave API.
  4. Em Senders, adicione e verifique skyticketservicee@gmail.com (ou o e-mail que quiser como remetente).
  5. Abaixo: modo = Brevo, cole a API key, guarde e teste. Se a conta Brevo ainda não estiver activada, use SendGrid.
