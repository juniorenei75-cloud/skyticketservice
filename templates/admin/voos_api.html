✈ Bilhetes em tempo real (por companhia)

O SKYTICKETservice é um sistema real de agência. As ofertas ao cliente vêm apenas de API (Duffel / Amadeus / Kiwi), do catálogo da agência ou de cotação pela equipa. Não se inventam bilhetes.

1) Duffel (recomendado para começar)

  1. Crie conta em app.duffel.com/join
  2. No painel: Developers → Access tokens
  3. Copie um token duffel_test_… (testes) ou duffel_live_… (produção)
  4. Cole abaixo → Guardar → Testar ligação

Documentação: duffel.com/docs. Com token de teste pode pesquisar ofertas reais de sandbox; para vender e emitir, use token live e complete a verificação da conta na Duffel.

Percentagem adicionada ao preço Duffel. Ex.: bilhete a 100 USD com 5% → cliente paga 105 USD. A margem fica para a SKYTICKETservice.

Fluxo real com Duffel

  1. Cliente pesquisa no site → SKYTICKET chama a Duffel
  2. Duffel devolve ofertas por companhia (preço, voo, horário)
  3. Cliente escolhe e completa dados → a agência confirma / emite (ou reserva via Duffel Orders em fase seguinte)
